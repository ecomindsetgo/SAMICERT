# SAMICERT

Versión actualizada.

Cambios:
- El PDF certificado se retira inmediatamente de la pantalla después de completar la certificación y guardar el resultado.
- El módulo Verificar Documento muestra el nombre del PDF seleccionado y un estado visible mientras calcula y consulta el registro.
- Se mantiene la consulta automática por SHA-256 sin mostrar la huella para copiar.
- Los mensajes visibles no mencionan Firebase; utilizan "almacenado" o "registrado automáticamente".
- Los sellos se asignan automáticamente según el usuario autenticado.
- Tamaño del sello: 90 pt.
- Margen: 3 pt.
