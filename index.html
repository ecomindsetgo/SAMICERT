Acerca de SAMICERT

Conozca el propósito del sistema, su funcionamiento y las medidas utilizadas para conservar los registros de certificación.

Importante: una vez registrada una certificación, su información queda protegida mediante las reglas de seguridad del sistema. El identificador y SHA-256 se almacenan automáticamente y no se presentan como datos para copiar.

Finalidad

SAMICERT permite certificar documentos PDF aplicando automáticamente el sello correspondiente al usuario autenticado y registrar la certificación para su posterior verificación.

Integridad documental

El sistema calcula el SHA-256 sobre los bytes exactos del PDF final después de aplicar el sello. Esa huella queda registrada automáticamente en Firestore.

Seguridad

El acceso requiere autenticación. Las certificaciones registradas están protegidas para impedir modificaciones o eliminaciones desde la aplicación.
